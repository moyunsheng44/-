# 钢铁战线

双人轮流制卡牌对战游戏，Python + Tkinter 实现。

## 运行

```bash
python main.py
```

要求 Python 3.10+，无需额外依赖。

## 玩法

- 双方各 20 生命，轮流行动，将对方总部生命归零获胜
- 每回合费用自动补充（上限逐回合 +1，最高 10），打牌/移动/攻击消耗费用
- 后方战场最多 5 张卡（总部占 1，单位最多 4），前线最多 5 单位
- 地面单位（步兵/坦克）需推进前线或攻击相邻战场；战斗机可从任意位置攻击
- 步兵一回合只能移动或攻击一次；坦克可移动并攻击

## 卡牌类型

| 类型 | 说明 |
|------|------|
| 步兵 | 一回合只能移动或攻击 |
| 坦克 | 一回合可移动并攻击 |
| 战斗机 | 空中单位，不受战线限制 |
| 指令 | 法术牌，伤害/治疗/抽牌/费用槽 |

## 关键词

- **闪击**：部署当回合即可行动（新兵步兵）
- **爆牌**：手牌满 10 张时新抽的牌弃置
